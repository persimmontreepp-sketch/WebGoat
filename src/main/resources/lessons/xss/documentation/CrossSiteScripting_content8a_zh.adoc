== 什么是编码？

不要信任用户输入意味着：每当数据穿过信任边界（例如从 Web 表单传到应用脚本）时，都要验证其类型、长度、格式和范围；在动态页面中重新显示之前，还要进行编码。

在实践中，这意味着你需要检查网站中处理用户提供数据的每个位置，并确保客户端提供的值在返回给用户之前都经过检查、过滤和编码。

不能依赖客户端验证，但可以在 Web 应用使用用户输入之前，通过服务器端处理将其限制为最少的字母数字字符集合。

== 转义

转义是指转换（或标记）数据中的关键字符，防止其在危险上下文中被解释。对于 HTML 输出，需要转换 `<` 和 `>` 等字符，以防止恶意代码被渲染。转义这些字符时要将其转换为对应的实体 `\&lt;` 和 `\&gt;`，这样浏览器就不会将它们解释为 HTML 标签。

== 特殊字符

如果 `<` 和 `>` 等特殊字符来自用户输入，在重新显示之前就必须对其编码。例如，对 `<` 和 `>` 编码可确保浏览器会显示 `<script>`，但不会执行它。编码的同时，网页还必须始终定义字符集，以免浏览器将其他字符集中的特殊字符编码错误地解释为内容。

跨站脚本攻击通常是在他人的网站上设法插入脚本（通常是 JavaScript），并让脚本恶意运行。
