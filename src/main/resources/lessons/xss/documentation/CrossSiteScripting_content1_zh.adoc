== 什么是 XSS？

跨站脚本（也称 XSS）是一种漏洞/缺陷：应用允许用户输入 HTML/脚本标签，但在将其呈现在浏览器中之前没有进行编码或清理。

=== 跨站脚本（XSS）是最普遍、危害最大的 Web 应用安全问题之一

尽管有一种简单且广为人知的防御方法，但 Web 上仍有大量 XSS 漏洞。修复覆盖面也往往是个问题。稍后我们会进一步讨论防御方法。

=== XSS 影响重大

随着“富互联网应用”日益普遍，通过 JavaScript 链接调用的特权功能可能遭到攻击。
如果防护不足，身份验证 Cookie 等敏感数据可能被窃取并用于他人目的。

==== 简单示例：
* 在浏览器（Chrome、Firefox）的开发者工具中打开 JavaScript 控制台：
+
----
alert("XSS Test");
alert(document.cookie);
----
* 返回给客户端的任何数据字段都可能遭到注入：
+
----
<script>alert("XSS Test")</script>
----

== 动手试试！使用 Chrome 或 Firefox

* 打开第二个标签页，并访问与你当前页面相同的 URL（也可以访问此 WebGoat 实例中的任意 URL）。
* 在第二个标签页的开发者工具中打开 JavaScript 控制台，输入：`alert(document.cookie);`。
* 两个标签页中的 Cookie 应该相同。
