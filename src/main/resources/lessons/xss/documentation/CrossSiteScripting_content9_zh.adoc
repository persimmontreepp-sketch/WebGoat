==== jQuery
请注意，如果你使用类似下面的代码：

`_$selector.html(userInputHere)_`

就会面临危险。如果确实需要使用它，请确保采用类似下面的方式：

`_$selector.html(someEncodeHtmlMethod(userInputHere))_`

或者：

`_$selector.*text*(someEncodeHtmlMethod(userInputHere))_`

如果只想获取用户输出的文本（http://stackoverflow.com/questions/9735045/is-jquery-text-method-xss-safe#9735118）
