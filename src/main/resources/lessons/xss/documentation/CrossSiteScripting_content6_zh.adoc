== 反射型和基于 DOM 的 XSS

基于 DOM 的 XSS 是反射型 XSS 的另一种形式。两者都是通过发送链接触发，输入内容会在浏览器中反映出来。DOM 型 XSS 与“传统”反射型 XSS 的区别在于：DOM 型载荷不会发送到服务器，只由客户端处理。

* 攻击者向受害者发送恶意 URL
* 受害者点击链接
* 链接可能会打开恶意网页，也可能打开受害者正在使用（已登录？）且包含易受攻击路由/处理程序的网页
* 如果打开的是恶意网页，它可能使用自己的 JavaScript 攻击另一个包含易受攻击路由/处理程序的页面/URL
* 易受攻击的页面呈现载荷，并在该页面/网站的用户上下文中执行攻击
* 攻击者的恶意脚本可能会以本地账户权限运行命令

*受害者没有意识到攻击已经发生*……恶意攻击者不会使用 &lt;script&gt;alert('xss')&lt;/ script&gt;
