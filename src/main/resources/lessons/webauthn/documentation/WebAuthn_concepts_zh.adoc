== 概念

=== 依赖方、RP ID 和来源

*依赖方*（RP）是希望对用户进行身份验证的网站。每个凭据都限定在一个*RP ID* 下，例如域名 `goatbank.example`。浏览器只允许网页使用与自身主机名相同或属于其可注册后缀的 RP ID。`https://login.goatbank.example` 上的页面可以使用 RP ID `goatbank.example`；`https://goatbank.evil.example` 上的页面则不可以。

WebAuthn 要求使用*安全上下文*：页面必须通过 `https://` 提供服务，开发环境中仅 `http://localhost` 是例外。不能使用 IP 地址作为 RP ID。

=== 身份验证器

[cols="1,3"]
|===
|平台身份验证器 |内置于设备中：Touch ID / Face ID、Windows Hello、Android 屏幕锁定。
|漫游式（跨平台）身份验证器 |可用于任何计算机的独立设备：例如通过 USB、NFC 或蓝牙连接的 *YubiKey* 或 Titan 安全密钥，或通过*混合*传输方式连接的手机（扫描 QR 码，并通过蓝牙检查设备距离）。
|===

=== 通行密钥和安全密钥

*通行密钥*是一种*可发现*凭据：身份验证器会将用户账户与密钥一起存储，因此用户无需输入用户名即可登录。由 Apple、Google 或密码管理器管理的通行密钥会在设备之间*同步*。安全密钥上的凭据则是*设备绑定的*：私钥无法导出，因此必须持有该实体密钥才能完成身份验证。

安全密钥也可以创建*不可发现*凭据。此时，密钥不会存储任何信息；私钥会被包装（加密）在服务器保存的凭据 ID 中，并由服务器在登录期间将该凭据 ID 发回（`allowCredentials`）。安全密钥作为第二因素时就是这样使用的。

=== 标志

每个响应都包含 `authenticatorData`，其中带有服务器应检查的标志：

[cols="1,4"]
|===
|UP（用户在场） |有人触碰了密钥或确认了提示。
|UV（用户已验证） |身份验证器已确认*用户身份*：通过 PIN、指纹或面部识别。凭据作为唯一因素时必须进行此验证。
|BE / BS（可备份/已备份） |凭据可以（且已经）同步到其他设备。安全密钥始终为 false。
|AT（证明凭据数据） |其中包含新的公钥（注册时）。
|===

=== 服务器存储的内容

对于每个凭据，依赖方都会保存一条记录：

* *凭据 ID*；
* *公钥*（COSE 格式）及其算法，例如 ES256（`-7`）；
* *签名计数器*，许多安全密钥会在每次使用时递增此值；
* *用户句柄*：身份验证器在登录期间返回的账户标识符。规范要求它是最多 64 字节的不透明随机值，不得包含用户名或电子邮件地址等个人信息；
* 可选的 *AAGUID*（身份验证器型号）和证明信息。
