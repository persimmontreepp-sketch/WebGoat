= 密码存储

安全存储密码并不容易，因为攻击者一旦窃取凭据数据库，就可以在自己的硬件上测试猜测。存储设计决定了攻击者需要什么，以及每次猜测的成本有多高。

本课程将介绍密码存储为何需要：

* 使用针对密码的密钥派生函数，而不是速度很快的通用哈希函数；
* 为每个密码设置唯一的公开盐值；
* 将任何秘密 pepper 与密码数据库谨慎分开。

Daily Byte 博客为读者和作者存储密码。Maria 可以发布和编辑所有文章，因此她的账户成为目标。

你获得了博客用户数据库的副本。每项练习都会展示一种新的密码存储方式。密码和训练用词表都是虚构的。请勿输入真实密码。

获得密码验证值后，攻击者无需联系应用就可以测试猜测。这是*离线攻击*。登录速率限制无法减缓这种攻击。

本课程将探讨离线攻击者需要哪些数据，以及每次猜测需要多少计算量。
