== 第 3 阶段：增加每次猜测的成本

博客将 SHA-256 替换为 Argon2id。Argon2id 是密码密钥派生函数。其内存和时间成本会增加每次测试候选密码的成本。

编码值采用 PHC 字符串格式：

[source,text]
----
$argon2id$v=19$m=19456,t=2,p=1$salt$output
----

这些字段依次标识算法、版本、以 KiB 为单位的内存、迭代次数、并行度、盐值和派生输出。没有任何字段需要保密。

读取 Maria 的编码值并提交参数。还要选择准确的成本比较。

不存在适用于所有情况的“每秒猜测次数”。硬件、参数、库和可用内存都会影响结果。稳定的比较是：此 Argon2id 配置对每次猜测需要 19 MiB 工作内存和两轮计算，而单次 SHA-256 摘要没有可比的内存成本。
