== 各项措施的作用

[cols="1,2,2",options="header"]
|===
|措施 |可以防范 |无法解决

|唯一盐值
|预计算表和跨账户重复利用计算结果。它还能隐藏密码相同这一事实。
|针对弱密码的离线猜测。

|Argon2id
|廉价的候选密码测试。可配置的内存和时间成本会提高每次猜测的成本。
|让弱密码变得无法猜测，或防止所有必需验证机密被盗。

|Pepper
|pepper 保持机密并由独立系统控制时，可防范仅数据库泄露。
|pepper 也遭到泄露，或能够使用 pepper 的应用运行时遭到攻陷。
|===

应根据应用硬件和容量选择当前参数。测量身份验证延迟和内存使用情况，并随着硬件和指导建议的变化定期审核配置。

延伸阅读：https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html[OWASP 密码存储备忘单,window=_blank] 和 https://www.rfc-editor.org/rfc/rfc9106.html[RFC 9106,window=_blank]。
