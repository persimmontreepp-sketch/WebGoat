== 第 4 阶段：仅有数据库已不足以验证密码

博客采用以下结构加入 pepper：

[source,text]
----
argonResult = Argon2id(password, uniqueSalt, parameters)
storedVerifier = HMAC-SHA-256(key=pepper, data=argonResult)
----

数据库保存盐值、Argon2id 参数、HMAC 算法和最终验证值。它不会保存 `argonResult` 或 pepper。

你通过模拟 SQL 注入获取了完整数据库。请判断转储数据中是否包含验证离线猜测所需的全部内容，并指出缺少哪个值。

Pepper 是共享机密。只有当窃取数据库的攻击者无法获得它时，pepper 才能提供额外保护。它不能替代密码 KDF、唯一盐值、强密码或访问控制。
