== 试试看！编写安全代码

现在轮到你编写自己的代码了！
你的任务是使用 JDBC 连接数据库并从中查询数据。

*要求：*

* 连接到数据库
* 执行一个能够抵御 SQL 注入攻击的数据库查询
* 查询中至少包含一个字符串参数

*开始之前的一些提示：* +
连接数据库时，可以假定常量 *DBURL*、*DBUSER* 和 *DBPW* 已经定义好。+
只要 SQL 语句有效且满足要求，查询内容并不重要。+
你编写的所有代码都会插入到名为 `TestClass` 的 Java 类的 main 方法中，且该类已为你导入 *java.sql.**。

想不出自己的查询？可以试着从一个虚构的 users 数据表中获取指定用户名的数据。

例如，以下代码可以编译通过（但当然不满足完成本课程的要求）。

[source,java]
-------------------------------------------------------
try {
    Connection conn = null;
    System.out.println(conn);   //应输出 'null'
} catch (Exception e) {
    System.out.println("Oops. Something went wrong!");
}
-------------------------------------------------------

运用你学到的知识，在下方编辑器窗口中从头编写有效代码！
（如果无法在编辑器中输入，可以尝试调整浏览器窗口大小，然后再试。）
