=== 数据操作语言（DML）

顾名思义，数据操作语言用于处理数据。许多最常见的 SQL 语句都属于 DML 语句，包括 SELECT、INSERT、UPDATE 和 DELETE。DML 语句可用于查询记录（SELECT）、添加记录（INSERT）、删除记录（DELETE）以及修改现有记录（UPDATE）。

如果攻击者成功向 SQL 数据库“注入”DML 语句，就能破坏系统的机密性（使用 SELECT 语句）、完整性（使用 UPDATE 语句）和可用性（使用 DELETE 或 UPDATE 语句）。

* DML 命令用于存储、检索、修改和删除数据。
* SELECT——从数据库中检索数据
* INSERT——向数据库插入数据
* UPDATE——更新数据库中已有的数据
* DELETE——删除记录
* 示例：
** 检索数据：
** SELECT phone  +
   FROM employees +
   WHERE userid = 96134;
** 此语句会检索 userid 为 96134 的员工电话号码。
