== 试试看！字符串 SQL 注入

代码中的查询会像前面的示例一样构造动态查询。该查询通过拼接字符串构建，因此容易受到字符串 SQL 注入攻击：

------------------------------------------------------------
"SELECT * FROM user_data WHERE first_name = 'John' AND last_name = '" + lastName + "'";
------------------------------------------------------------

试着使用下方表单从 users 表中获取所有用户。你无需知道任何特定用户名就能获得完整列表。
