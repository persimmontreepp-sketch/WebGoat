== 什么是 SQL？

SQL 是一种标准化（1986 年 ANSI 标准、1987 年 ISO 标准）的编程语言，用于管理关系型数据库并对其中的数据执行各种操作。

数据库是数据的集合。数据按行、列和表组织，并通过索引提高查找相关信息的效率。

下面是一个包含员工数据的 SQL 表示例；表名为 `employees`：

员工表
|===
|用户 ID |名字 |姓氏 |部门 |薪水 |交易认证码（TAN）

|32147|Paulina|Travers|会计|$46.000|P45JSI|
|89762|Tobi|Barnett|开发|$77.000|TA9LL1|
|96134|Bob|Franco|市场营销|$83.700|LO9S2V|
|34477|Abraham|Holman|开发|$50.000|UU2ALK|
|37648|John|Smith|市场营销|$64.350|3SL99A|

|===

某公司在数据库中保存以下员工信息：唯一员工编号（`userid`）、姓氏、名字、部门、薪水以及交易认证码（`auth_tan`）。每条信息分别存储在一个列中，每行表示一名公司员工。

SQL 查询可用于修改数据库表及其索引结构，也可用于添加、更新和删除数据行。

SQL 命令主要分为三类：

* 数据操作语言（DML）
* 数据定义语言（DDL）
* 数据控制语言（DCL）

攻击者可以利用每类命令破坏系统的机密性、完整性和/或可用性。继续学习课程，了解不同类型的 SQL 命令及它们与安全目标之间的关系。
