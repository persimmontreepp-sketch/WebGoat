== 仅靠输入验证还不够！！

你需要同时使用参数化查询，并验证从用户处收到的输入。在 StackOverflow 上，你会看到许多答案称输入验证就够了。*但是*，只要时间一长，就会发现验证被绕过，应用中仍存在 SQL 注入漏洞。

有关为何仅靠输入验证不够的精彩讨论，请参阅：https://twitter.com/marcan42/status/1238004834806067200?s=21

我们再做一次之前的练习。开发人员尝试通过过滤修复潜在的 SQL 注入问题，你能发现这种方法的弱点吗？
