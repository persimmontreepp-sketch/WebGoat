=== 数据控制语言（DCL）

数据控制语言用于在数据库中实施访问控制逻辑。DCL 可用于撤销或授予用户对表、视图和函数等数据库对象的权限。

如果攻击者成功向数据库“注入”DCL 类型的 SQL 命令，就能通过 GRANT 命令破坏系统的机密性，并通过 REVOKE 命令破坏可用性。例如，攻击者可以给自己授予数据库管理员权限，或撤销真正管理员的权限。

* DCL 命令用于对数据库对象实施访问控制。
* GRANT——授予用户访问数据库对象的权限
* REVOKE——撤销之前使用 GRANT 授予用户的权限
