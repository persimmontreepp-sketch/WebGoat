== 使用查询链接破坏完整性
上一课破坏了数据的机密性，本课将使用 SQL *查询链接*破坏数据的*完整性*。

如果漏洞足够严重，攻击者就可能通过 SQL 注入破坏数据库中任何数据的完整性。成功利用 SQL 注入后，攻击者甚至可能修改其本无权访问的信息。

=== 什么是 SQL 查询链接？
顾名思义，查询链接就是试图在实际查询末尾追加一条或多条查询。可以使用元字符 *;* 来实现。*;* 用于标记 SQL 语句的结束，因此可以紧接初始查询开始另一条查询，无需换行。
