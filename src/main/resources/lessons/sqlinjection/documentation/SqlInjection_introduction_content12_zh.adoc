== 试试看！数值型 SQL 注入

代码中的查询会像前面的示例一样构造动态查询。该查询通过拼接数字构建，因此容易受到数值型 SQL 注入攻击：

--------------------------------------------------
"SELECT * FROM user_data WHERE login_count = " + Login_Count + " AND userid = "  + User_ID;
--------------------------------------------------

使用下方的两个输入框，试着从 users 表中获取所有数据。

警告：只有一个输入框容易受到 SQL 注入攻击。你需要找出是哪一个，才能成功获取全部数据。
