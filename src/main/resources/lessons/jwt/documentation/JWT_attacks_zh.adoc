== 攻击

JSON Web Token（JWT）已广泛用于在各方之间安全传输信息。不过，和任何技术一样，它也容易受到某些漏洞和攻击。以下是一些常见 JWT 攻击的概述：

- **篡改令牌过期时间**：JWT 通常包含指示过期时间的 `exp` 声明。攻击者可能会尝试修改此声明以延长令牌有效期，使其在预期过期时间后仍可继续使用。

- **篡改令牌**：攻击者可能修改令牌内容，例如载荷或头部中的声明，以冒充其他用户、获取未授权访问权限或更改权限。

- **令牌泄露**：如果 JWT 未在客户端安全存储（例如保存在 Cookie 或本地存储中），就可能受到跨站脚本（XSS）攻击，导致令牌泄露和潜在的未授权访问。

- **暴力破解攻击**：由于 JWT 自包含，攻击者可能尝试使用各种密钥组合来暴力破解签名，从而伪造有效签名。

- **密钥混淆攻击**：如果 `kid`（密钥 ID）声明遭到滥用或验证不当，攻击者可能操纵该声明，在验证签名时使用另一把密钥，从而获得未授权访问。

- **重放攻击**：攻击者可能捕获有效 JWT，并在其有效期内多次使用，以冒充原用户或重复执行特定操作。

- **令牌侧信道窃取**：如果 JWT 通过不安全通道（例如未加密的 HTTP）传输，攻击者就可能拦截并窃取令牌，从而未授权访问用户账户。

- **算法降级攻击**：攻击者可能尝试修改头部中的 `alg` 声明，强制使用较弱的密码学算法。

- **伪造令牌**：如果验证不健全，攻击者可能构造自己的 JWT，从而绕过身份验证或授权检查。

- **篡改时钟**：如果服务器时钟可以被操纵，攻击者可能调整服务器时间，延长已过期令牌的有效期。

本课程将介绍一些常见攻击，让你了解可能出现的问题以及如何保护自己。
