= JWT 令牌

== 概念

本课程介绍如何使用 JSON Web Token（JWT）进行身份验证，以及使用 JWT 时需要注意的常见问题。

== 目标

学习如何安全地实现令牌的使用及其验证。

== 简介

许多应用使用 JSON Web Token（JWT），让客户端在身份验证后使用令牌表明自身身份，以便继续进行交互。

摘自 https://jwt.io/introduction：
-------------------------------------------------------
JSON Web Token（JWT）是一项开放标准（RFC 7519），它定义了一种紧凑且自包含的方式，让各方以 JSON 对象的形式安全地传输信息。这些信息可以验证并可信，因为它们带有数字签名。JWT 可以使用机密（通过 HMAC 算法）或 RSA 公钥/私钥对进行签名。

JSON Web Token 用于携带与客户端身份及其特征（声明）相关的信息。服务器会对此“容器”签名，以防客户端篡改它，例如更改身份或其他特征（例如，将普通用户的角色改为管理员，或更改客户端登录信息）。此令牌在身份验证过程中创建（身份验证成功后提供），服务器会在处理任何请求之前验证令牌。应用使用它让客户端向服务器提交代表其“身份证”的令牌（包含用户全部信息的容器），服务器则以无状态且可移植的方式安全验证令牌的有效性和完整性。所谓可移植，是指客户端和服务器技术可以不同，传输通道也可以不同（尽管最常用的是 HTTP）。
-------------------------------------------------------
