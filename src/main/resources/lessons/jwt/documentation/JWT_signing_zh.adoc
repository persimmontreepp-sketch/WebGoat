== JWT 签名

每个 JWT 令牌在发送给客户端之前都应进行签名。如果令牌未签名，客户端就可以更改令牌内容。签名规范见 https://tools.ietf.org/html/rfc7515[此处]，可用的具体签名算法见 https://tools.ietf.org/html/rfc7518[此处]（_你需要在练习前阅读相关内容_）。

实践中，JWT 通常通过以下方式之一进行签名：

- 使用 SHA-2 的 HMAC _（对称密钥）_
- 使用 RSASSA-PKCS1-v1_5、ECDSA 或 RSASSA-PSS 的数字签名 _（非对称密钥）_

这些算法可以确保令牌完整性，并让服务器验证令牌是否遭到篡改。

=== 检查签名

一个重要步骤是，在执行其他操作之前*验证签名*，以免使用遭到篡改的令牌。
