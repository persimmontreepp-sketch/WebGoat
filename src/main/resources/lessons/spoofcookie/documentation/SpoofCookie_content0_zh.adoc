= 伪造身份验证 Cookie

尝试通过伪造身份验证 Cookie 绕过身份验证机制。

*关于登录系统的说明*

收到有效的身份验证 Cookie 时，系统会自动为用户登录。

如果未发送 Cookie，但提供的凭据正确，系统会生成身份验证 Cookie。

其他情况下，登录尝试都会被拒绝。
