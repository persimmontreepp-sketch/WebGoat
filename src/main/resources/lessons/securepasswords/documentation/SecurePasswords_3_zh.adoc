=== 你的密码安全吗？

你自己的密码安全吗？

有一些专门的网站可以查询你的某个账户是否曾在数据泄露事件中暴露。+
例如，访问 https://haveibeenpwned.com/Passwords[Have I Been Pwned] 或 https://www.dehashed.com/[DEHASHED]，检查你的账户是否曾被泄露。如果是，请立即更换密码！

==== 如何提高账户安全性？
- *不同账户使用不同密码* +
不要在多个账户中重复使用相同密码，而应为不同账户设置不同密码。
* *使用密码短语* +
使用 https://www.rempe.us/diceware/#eff[Diceware] 等密码短语生成器。密码短语由多个单词构成，而不是随机生成的字符序列。这对人类来说容易记忆得多。顺便说一句，越长越好！
* *使用密码管理器* +
如果记不住不同的密码，可以使用密码管理器生成并安全地保存密码。
- *使用双因素身份验证* +
如果条件允许，请使用双因素身份验证，为账户增加一层安全保护。
