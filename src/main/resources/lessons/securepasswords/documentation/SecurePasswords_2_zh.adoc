=== NIST 密码标准

NIST 密码标准（又称 https://pages.nist.gov/800-63-3/sp800-63b.html[特别出版物（SP）800 系列]）是一份为安全密码系统的实施提供建议的指南。

==== 密码规则
以下是最新版 NIST 标准中一些重要建议：

- *不要规定字符组合规则* +
不要要求用户的密码必须包含至少一个大写字母和一个特殊字符等。可以允许他们这样设置，但不要强制要求！
- *不要提供密码提示* +
如果你想让别人更容易猜到你的密码，就把它写在便签上贴在屏幕上。
- *不要使用安全问题* +
安全问题也称为基于知识的身份验证（KBA），这种方式已经过时。询问用户“你的宠物叫什么名字？”之类的问题来确认身份，非常不安全。
- *不要无故更换密码* +
如果希望用户遵守要求并选择较长且难以猜测的密码，就不应要求他们仅仅因为经过了一段时间而不必要地更换密码。
- *至少 8 个字符* +
如今，安全密码至少应有 8 个字符（最多可达 64 个）。这是最小长度，不应再设置更短的下限！
- *支持所有 UNICODE 字符* +
密码应允许使用各种 UNICODE 字符，包括表情符号和空白字符。
- *检查密码是否属于已知的不安全选择*
* 之前数据泄露事件中出现过的密码
* 字典词语
* 重复或连续字符（例如 `'aaaaaa'`、`'1234abcd'`）
* 与具体场景有关的词语，例如服务名称、用户名及其变体

==== 易用性

除了上述建议外，NIST 标准还建议提高密码表单的易用性，从而增加用户选择强密码和安全密码的可能性。建议包括：

- *允许将密码粘贴到输入框中* +
输入密码时应允许使用“粘贴”功能。这有助于使用密码管理器，也会提高用户选择强密码的可能性。
- *允许显示密码* +
密码输入框应提供显示已输入密码的选项，帮助用户正确输入密码。
- *提供强度计* +
在创建密码的页面添加强度计，帮助用户选择强密码和安全密码。
