=== 什么是跨站请求伪造？

跨站请求伪造也称为单击攻击或会话骑劫，缩写为 CSRF（有时读作 sea-surf）或 XSRF。这是一种针对网站的恶意利用：攻击者让网站信任的用户发出未经授权的命令。跨站脚本（XSS）利用用户对特定网站的信任，而 CSRF 利用网站对用户浏览器的信任。

跨站请求伪造是一种针对 Web 浏览器的“混淆代理”攻击。CSRF 通常具有以下特征：

* 涉及依赖用户身份的网站。
* 利用网站对该身份的信任。
* 诱骗用户的浏览器向目标网站发送 HTTP 请求。
* 涉及会产生副作用的 HTTP 请求。

基于可信且经过身份验证的用户输入执行操作，却没有要求用户授权具体操作的 Web 应用容易受到攻击。通过浏览器 Cookie 进行身份验证的用户，可能在不知情的情况下向信任该用户的网站发送 HTTP 请求，从而导致非预期操作。

CSRF 攻击会针对或滥用基本的 Web 功能。如果网站允许导致服务器状态改变的操作，例如修改受害者的电子邮件地址或密码，或进行购物，就可能受到攻击。强迫受害者获取数据对攻击者没有帮助，因为攻击者收不到响应，只有受害者能收到。因此，CSRF 攻击针对的是会改变状态的请求。
