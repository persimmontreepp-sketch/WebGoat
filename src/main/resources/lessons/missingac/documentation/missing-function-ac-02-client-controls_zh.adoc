== 依赖隐蔽性

开发人员可能依赖 HTML、CSS 或 JavaScript 隐藏用户通常无法访问的链接。过去，有一台网络路由器试图通过 UI 中的 JavaScript 保护（隐藏）管理员功能：https://www.wired.com/2009/10/routers-still-vulnerable。

=== 查找隐藏项目

通常可以从以下内容中找到 UI 未公开显示的功能线索：

* HTML 或 JavaScript 注释
* 被注释掉的元素
* 通过 CSS 控制或类隐藏的项目
