== 安全信息过载

=== 重要的是什么？

* 我的组件是否可被利用？
* 我的组件是否为正版？
** 我是否了解组件被修改的原因？

=== 安全信息散落各处

* 多种安全公告来源
** 国家漏洞数据库（NVD）中有 80,000 多个 CVE
** Node Security Project、Metasploit、VulnDB、Snyk 等
** 数以千计的网站安全公告、博客、推文等
* GitHub 每天生成 60 万个事件
** 其中 700 个与 GitHub 安全相关
** 发行说明、变更日志、代码注释等

=== 总结

* 不应期望开发人员不断研究每个组件。
* 开发人员不是安全专家；他们已经有本职工作要做。
