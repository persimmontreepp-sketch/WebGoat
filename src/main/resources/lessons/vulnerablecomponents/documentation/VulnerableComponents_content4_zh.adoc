== 如何生成物料清单

有多种开源和付费解决方案能够识别组件风险。不过，能够列出应用中所用全部“配料”的工具并不多。OWASP Dependency-Check 可以生成物料清单并识别潜在安全风险。

Dependency-Check 会根据多项证据来确定库名称。例如，你可以将 OWASP Dependency-Check 作为插件添加到 Maven 项目的 `pom.xml` 中。该插件会从公共漏洞数据库下载信息，检查是否使用了存在漏洞的库，并指出报告了哪些漏洞。

在开发流水线中，可以指示插件在出现开发团队尚未意识到的违规问题时使构建失败。此外，也可以使用 XML 文件豁免某些违规项。如果提到的漏洞无法在你的应用中被利用，可以这样做。

WebGoat 的父级 `pom.xml` 中有一个示例：

[source,xml]
----
<plugin>
	<groupId>org.owasp</groupId>
	<artifactId>dependency-check-maven</artifactId>
	<version>5.3.2</version>
	<configuration>
		<failBuildOnCVSS>7</failBuildOnCVSS>
		<skipProvidedScope>true</skipProvidedScope>
		<skipRuntimeScope>true</skipRuntimeScope>
		<suppressionFiles>
			<suppressionFile>project-suppression.xml</suppressionFile>
		</suppressionFiles>
	</configuration>
	<executions>
		<execution>
			<goals>
				<goal>check</goal>
			</goals>
		</execution>
	</executions>
</plugin>
----

以下是被豁免违规项的示例：

[source,xml]
----
<?xml version="1.0" encoding="UTF-8"?>
<suppressions xmlns="https://jeremylong.github.io/DependencyCheck/dependency-suppression.1.3.xsd">
    <suppress base="true">
        <cpe>cpe:/a:pivotal_software:spring_security</cpe>
        <cve>CVE-2018-1258</cve>
    </suppress>
    <suppress base="true"><!-- webgoat-server -->
        <cpe>cpe:/a:postgresql:postgresql</cpe>
        <cve>CVE-2018-10936</cve>
    </suppress>
</suppressions>
----

在 WebGoat 中，使用以下命令（owasp 配置）时会启用此插件：

	mvn clean install -Powasp
