== 什么是序列化

序列化是将对象转换为一种之后可以还原的数据格式的过程。人们通常会序列化对象，以便将其保存到存储介质中，或将其作为通信内容发送。反序列化则是相反的过程：获取按某种格式组织的数据，并将其重建为对象。如今，最常见的序列化数据格式是 JSON，在此之前则是 XML。

=== 原生序列化

许多编程语言都提供了原生对象序列化功能。这些原生格式通常比 JSON 或 XML 提供更多功能，包括自定义序列化过程。不过，在处理不可信数据时，这些原生反序列化机制也可能被重新利用来实施恶意操作。针对反序列化器的攻击可能导致拒绝服务、访问控制问题和远程代码执行。

=== 已知受影响的编程语言

* Python

* C++

=== 数据，而非代码

序列化的只有数据，代码本身不会被序列化。反序列化会创建新对象，并从字节流中复制所有数据，从而重建一个与原始序列化对象相同的对象。
