=== 暴露的 Actuator 端点

运维团队没有限制 Actuator 端点。互联网上的任何人都可以在未经身份验证的情况下访问 `/actuator/env` 和 `/actuator/health`，从而获取内部机密和状态信息。

步骤：

. 使用下方的按钮查询暴露的端点。
. 检查 JSON 响应并找到系统 API 密钥。
. 提交泄露的密钥以完成任务，并记录修复方法：锁定或禁用 Actuator 端点，或使用身份验证和网络过滤规则对其进行保护。

如果攻击者能够访问这些维护端点，就可以进一步获取敏感配置，甚至触发危险操作。

配置错误的端点一旦暴露环境变量、令牌或健康信息，攻击者就可以进一步访问其他 API、重放泄露的机密，或收集后续攻击所需的情报。应将 Actuator/管理控制台限制为可信网络访问，强制执行身份验证，并在生产环境中禁用敏感端点。
