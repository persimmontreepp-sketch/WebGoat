=== 简介

这些练习建立在 WebGoat 的专项课程之上。专项课程一次讲解一个安全概念。本节要求你在更大的应用中组合并运用这些概念，以实现一个目标。

练习会描述预期结果，但不会指出漏洞是什么，也不会给出达成目标的步骤。你需要自行决定检查应用的哪些部分、信任边界在哪里，以及不同弱点如何串联成一条攻击路径。可用的提示有限。需要回顾某个概念时，可以参考专项课程，然后自行调查当前场景。

浏览器工具、脚本、拦截代理和 AI 助手都可以用于练习。助手或许能快速生成载荷，但你仍需理解它为何有效、说明完整的攻击链，并判断建议的修复是否消除了根本弱点。

==== 练习须知

- 需要了解安全概念时，请参考专项课程。

- 请将操作限制在 WebGoat 应用内。不要攻击其他系统或学习者。

- 记录导致攻击得以实现的组件、信任边界和假设。

*先理解系统的行为，再验证发生了什么变化。*
