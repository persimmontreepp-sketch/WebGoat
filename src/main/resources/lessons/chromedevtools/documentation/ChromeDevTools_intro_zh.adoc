== Google Chrome 开发者工具

完成某些练习时，你可能需要查看 JavaScript 源代码或自行运行 JavaScript 命令。
Google Chrome 提供了一组工具来完成这些任务以及更多操作。
这些工具并非 Chrome 独有，几乎所有现代浏览器都有各自的一套开发工具。本简介将重点介绍 Google Chrome 中的工具。
你也可以使用自己偏好的浏览器，例如 Firefox 或 Safari，不过本教程中的部分步骤可能有所不同。

请注意，本教程并不打算讲解这些工具的全部功能，只介绍完成特定练习所需的基础知识。如果你已经熟悉这些工具，可以跳过相关课程。

首先，*打开开发者工具*。有多种打开方式：

1. 在浏览器窗口中的任意位置点击鼠标右键，然后选择 _“检查”_。
2. 打开浏览器菜单（右上角的三个点），选择 _“更多工具”_，再选择 _“开发者工具”_。
3. 使用键盘快捷键 _Ctrl + Shift + I_
