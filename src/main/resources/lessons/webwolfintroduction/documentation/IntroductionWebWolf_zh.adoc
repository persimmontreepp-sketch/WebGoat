== WebWolf 简介

只有当课程说明可以使用 WebWolf 时，你才需要使用它。很多课程只需使用 WebGoat，无需打开 WebWolf。
可以使用 WebWolf 的练习会在练习页面右上角显示以下图标：

{nbsp}

image::images/wolf-enabled.png[width=115,height=128]

{nbsp}

即使出现了这个图标，你也不一定要使用 WebWolf；你可以改用自己喜欢的拦截工具（例如 `netcat`）。

点击页面右上角的图标即可打开 WebWolf。它会在新的浏览器标签页中打开，是一个模拟攻击者机器的独立 Web 应用。这样可以清楚地区分目标网站上的操作和你作为“攻击者”需要执行的操作。

WebWolf 提供以下功能：

* 托管文件
* 接收请求的落地页

课程发送的邮件会投递到 WebGoat 自身的邮箱。点击 WebGoat 右上角、语言选择器旁边的信封图标即可查看。邮箱会在单独窗口中打开，信封图标上的数字表示未读邮件数量。
