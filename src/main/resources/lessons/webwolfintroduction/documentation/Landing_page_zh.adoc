== 落地页

此页面会显示发送到 `/landing/**` 的所有请求。因此，你可以在 XSS 等练习中使用 WebWolf 落地页接收请求，例如收集 Cookie。

*本练习需要先登录 WebWolf。*

{nbsp}
{nbsp}

假设我们诱使用户点击了邮件中的链接，该链接会打开我们精心制作的密码重置页面。页面看起来与公司常用的密码重置页面相同。用户输入新密码并提交后，你的主机就会收到该密码；在本练习中，密码会发送到 WebWolf。请尝试找到唯一代码。

请注意，用户重置密码后会看到错误页面。真实攻击中，用户通常会看到普通的成功页面；这是 WebWolf 当前可模拟能力的限制。
