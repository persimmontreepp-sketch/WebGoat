== 什么是 WebGoat？
---

欢迎你，`username:user[]`！

WebGoat 是一个刻意设计为不安全的应用程序，供开发者在其中练习 Java 应用程序及常见开源组件中经常出现的安全漏洞。

WebGoat 包含课程、练习和挑战。课程按类别组织，每节课包含说明和练习。建议你尝试最后的挑战；它们难度较高，并且不提供提示。

WebGoat 的目标是让你通过实践学习 Web 安全。它适合开发者和安全测试人员。

目前只有 WebGoat 的界面和简介提供中文翻译，其他课程内容可能仍为英文。欢迎你帮助改进中文翻译。

请以安全研究者的思维尝试完成 WebGoat 中的练习。

感谢你的关注！
