== ZAP 基础
本节将介绍 https://www.zaproxy.org/[Zed Attack Proxy（ZAP）]。

=== 什么是 ZAP？
ZAP（Zed Proxy Attack）是一款免费的开源 Web 扫描器和攻击代理工具，最初由 OWASP 开发，现在由 Checkmarx 维护。ZAP 允许渗透测试人员检查流量、修改浏览器收发的请求和响应，并生成报告，指出通过流量检查发现的各种已知漏洞。通常，无界面的 ZAP 会在使用持续交付的流水线中被动或主动报告安全问题。
这里我们将交互式使用 ZAP，主要用于查看和修改请求，以发现漏洞并解决练习。ZAP 有图形用户界面，也提供 HUD（抬头显示），后者通过浏览器与 ZAP 代理之间的 WebSocket 连接工作。

=== 安装 ZAP
* 首先下载并为你的操作系统安装 https://www.zaproxy.org/download/[ZAP]
* 启动 ZAP
* 直接从 ZAP 启动浏览器

=== 设置浏览器

由于根据浏览器不同，ZAP 代理 localhost 的设置也不同，我们建议参考以下说明：https://www.zaproxy.org/docs/desktop/start/proxies/

=== 在历史记录面板中过滤请求

在 ZAP 主窗口中点击 Filter（过滤器），参见下图。

image::images/zap-exclude.png[Exclude internal APIs from WebGoat,style="lesson-image"]

{nbsp} +

然后在 `URL Inc Regex` 框中输入：

[source]
----
.*WebGoat.*
----

在 `URL Exc Regex` 框中输入：

[source]
----
.*lesson.*.mvc.*
----

点击“Apply”关闭窗口后，ZAP 将不再显示 WebGoat 内部请求。

==== 配置断点过滤器

开始使用 ZAP 拦截请求之前，需要排除 WebGoat 框架的内部请求。否则，ZAP 也会在 WebGoat 内部运行所需的请求处停止。基本上，可以配置一个断点，在请求头包含 POST 时拦截请求。你可以添加其他规则，但需要排除轮询用的 `.mvc` 消息，否则会很烦人。

按如下方式设置断点：

==== 拦截并修改请求

按上述说明设置拦截，然后点击下方的提交按钮提交表单/请求。请求被拦截（触发断点）后，按如下方式修改：

* 将方法改为 GET
* 添加请求头 `x-request-intercepted:true`
* 删除请求正文，并改为发送值为 `Requests are tampered easily` 的查询字符串参数 `changeMe`（不包括单引号）

然后点击播放按钮，让请求继续发送。

注意：两个播放按钮的行为略有不同，这部分留给你自行尝试和探索。
