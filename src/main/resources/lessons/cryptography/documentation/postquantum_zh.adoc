== 后量子密码学

量子计算机已经出现，而且每年可用量子比特数量都在增加。量子计算机能够并将能够解密使用原本被认为安全的算法加密的信息。多年来，大量使用易受量子计算攻击的密码学技术加密的通信一直被记录下来。等量子计算机足够强大时，这些信息就会被解密。即使信息已经过时，其中仍可能包含有价值、可被滥用的内容，并且可能导致机密被披露给非预期接收方。

数学为后量子时代提供了解决方案。新的密码学技术已经可用，为了尽量降低威胁，现在就应该开始使用。请参阅 Wikipedia 了解更多信息：https://en.wikipedia.org/wiki/Post-quantum_cryptography[维基百科后量子密码学,window=_blank]
