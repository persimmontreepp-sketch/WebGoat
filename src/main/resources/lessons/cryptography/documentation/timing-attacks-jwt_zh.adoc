=== 与 JWT 的联系

使用 HS256 的 JWT 令牌会对以下签名输入进行身份验证：

----
base64url(header) + "." + base64url(payload)
----

身份验证使用 HMAC-SHA256。因此，JWT 签名本质上是 HMAC 认证值。如果 JWT 验证器使用依赖机密的提前退出方式来比较签名，就可能暴露相同的时序侧信道。

本课程中的攻击并未破解 HMAC-SHA256。服务器正确计算了安全的密码学原语，却在检查计算结果时泄露了信息。现有 JWT 课程对令牌结构和 JWT 专属攻击有更详细的介绍。
