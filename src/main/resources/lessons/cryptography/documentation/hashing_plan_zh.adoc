= 密码学基础

== 普通哈希

哈希是一种密码学技术，主要用于检测原始数据是否被更改。它通过不可逆的密码学方法，根据原始数据生成哈希值。
即使原始数据只改变一个字节，生成的哈希值也会不同。

从某种角度看，这似乎是一种安全技术。然而，哈希*并不适合，也永远不适合用于密码存储*。问题在于，攻击者可以从字典生成密码并计算各种变体。对于每个密码，都可以计算哈希值，然后将所有值存入大型数据库。这样，只要找到一个可能是密码的哈希值，就可以在数据库中查出对应密码。

不应再使用某些哈希算法：MD5、SHA-1。
对这些哈希，可以通过大量计算以某种方式更改载荷，同时仍然产生相同的哈希值。

== 加盐哈希

显然，不应该在数据库中存储明文密码；同样，也不应该存储普通哈希值。
