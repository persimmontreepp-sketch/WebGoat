=== 从噪声中提取信号

实际测量值会因调度、运行时活动、网络延迟和主机上的其他任务而变化。此端点会加入 0 到 8 毫秒的随机抖动，同时将匹配字节的信号降低到约 2 毫秒：

----
GET /WebGoat/crypto/timing/verify-noisy?message=WebGoat%20with%20noise&signature=00000000
----

本练习使用消息 `WebGoat with noise`，因此不能重复使用前一个练习恢复的标签。一次请求不再是有效证据。应对每个候选值多次采样，并比较中位数、平均值或截尾平均值等聚合统计量。本练习不要求使用某一种特定统计方法。

你可以逐步筛选候选项，以减少请求数量。对每个候选值测量几次，保留表现最强的一组，为该组增加样本，然后重复上述过程，直到只剩一个候选值。这是一种针对实现信息泄露的统计攻击，并不会恢复 HMAC 机密，也不会破解 SHA-256。
