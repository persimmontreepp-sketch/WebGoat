= 密码学基础

== 其他编码

此外还会使用其他编码。

=== URL 编码

发送表单数据和请求参数到服务器时经常使用 URL 编码。由于 URL 不允许包含空格，空格会替换为 `%20`。其他字符也会进行类似替换。

=== HTML 编码

HTML 编码可确保文本按原样显示在浏览器中，而不会被浏览器解释为 HTML。

=== UUEncode

Unix-to-Unix 编码曾用于发送电子邮件附件。

=== XOR 编码

有时会把编码用作一种简单的初步混淆技术来存储密码。例如，IBM WebSphere Application Server 使用特定的 XOR 编码实现来在配置文件中存储密码。IBM 建议保护这些文件的访问，并使用自定义加密替代默认 XOR 编码。然而，如果不遵循这些建议，默认设置就可能变成漏洞。
