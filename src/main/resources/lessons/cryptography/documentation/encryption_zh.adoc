= 加密

== 对称加密

对称加密基于一个共享机密，该机密同时用于加密和解密。因此，参与秘密交换的双方使用相同的密钥。

协议示例：

* AES
* 3DES

== 非对称加密

非对称加密基于由一对密钥构成的数学原理。这两个密钥通常称为私钥和公钥。私钥必须得到妥善保护，只有一方知道；其他人都可以自由使用公钥。使用私钥加密的内容可以由拥有公钥的人解密；使用公钥加密的内容则只能由私钥解密。

协议示例：

* RSA
* DSA

== HTTPS 同时使用对称和非对称密钥

以下简要描述打开浏览器并访问 HTTPS 网站时会发生什么。

* 浏览器连接到服务器并获取 Web 服务器证书。
* 浏览器检查信任库中是否包含证书签发者的证书，以确定是否信任签发者。信任库由操作系统和浏览器更新管理；在某些企业网络中，也由公司管理。浏览器会从证书中获取公钥。
* 浏览器生成随机字节以用于生成对称密钥，并使用服务器公钥加密这些字节。因此，只有服务器能够解密。
* 在此过程结束时，浏览器和 Web 服务器都会使用（在非对称密钥交换过程中）交换的对称密钥，对双方之间传输的消息进行加密和解密。

之所以使用对称密钥，是因为它们更适用于大量数据，且所需处理能力更少。不过，本课程仅介绍密码学的基础概念。请通过互联网查找这些主题的详细信息。
