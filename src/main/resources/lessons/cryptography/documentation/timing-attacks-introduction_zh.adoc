=== 时序攻击

消息认证码（MAC）可让接收方验证消息来自知道共享机密的人，并确认消息未被更改。HMAC 使用密码学哈希函数和密钥生成 MAC。

知道消息本身并不会泄露其 HMAC。本课程中，服务器会正确计算 `HMAC-SHA256(secret, message)`。弱点出现在后续应用代码比较预期标签和提供的标签时。

[quote]
强大的密码学无法保护你免受其周围代码泄露的信息影响。

练习使用已知消息 `WebGoat`。HMAC-SHA256 结果会截断为四个字节，以便在合理时间内完成实验。32 位认证标签不适合用于生产环境。你不需要暴力破解整个标签，而要利用时序信息。

服务器会为每个会话生成不同的 HMAC 机密，并动态计算每个预期标签。复制其他学习者的标签不会生效。
