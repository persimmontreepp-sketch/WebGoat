= 密码学基础

== Base64 编码

编码本身并不是真正的密码学，但它被广泛用于各种密码学相关标准，尤其是 Base64 编码。

Base64 编码是一种将各种字节转换为特定字节范围的技术。该范围内的字节均为可读 ASCII 字符。这样便能更轻松地传输二进制数据，例如机密或私钥。你甚至可以打印或抄写这些内容。
编码是可逆的。因此，拥有编码后的版本就能还原原始版本。

你可以在 Wikipedia 上找到更多细节。简单来说，它会逐个处理字节，将每组 6 位转换为可读字节（8 位）。因此，编码后数据大小大约增加 33%。

	Hello ==> SGVsbG8=
	0x4d 0x61 ==> TWE=

=== 基本身份验证

Web 应用有时会使用基本身份验证。它使用 Base64 编码。因此，至少应使用传输层安全协议（TLS，通常称为 HTTPS），以防止其他人读取发送到服务器的用户名和密码。

	$echo -n "myuser:mypassword" | base64
	bXl1c2VyOm15cGFzc3dvcmQ=

HTTP 请求头如下所示：

	Authorization: Basic bXl1c2VyOm15cGFzc3dvcmQ=
