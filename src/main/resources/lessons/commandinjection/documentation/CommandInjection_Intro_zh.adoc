=== 什么是命令注入？

当用户可控的数据未经严格验证或参数化，就被传给操作系统 shell 时，便会发生命令注入。应用可能会将输入包装在辅助命令中（如 `ping`、`cat`、`dir`），但如果它委托给 `/bin/sh`、`cmd.exe` 或其他 shell，攻击者就能跳出预期命令，执行当前进程权限允许的任意操作。

常见成因包括：

* 使用 `Runtime.exec`、`ProcessBuilder` 或 `popen` 时拼接字符串。
* 构造命令行参数时信任用户输入（例如调用 shell 命令的备份脚本或日志查看器）。
* 试图通过删除少数元字符来清理输入，却漏掉了其他字符。

影响取决于应用运行账户的权限。至少，攻击者可以读取数据、转入本地网络，或植入后门。最严重时，他们可能完全控制主机。
