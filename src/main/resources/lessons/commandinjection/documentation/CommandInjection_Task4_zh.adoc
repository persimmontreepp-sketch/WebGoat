=== 绕过过滤器：泄露 API 密钥

运维团队发现有人在链接命令，于是快速添加了一份拒绝列表：服务器现在会在把你的猫咪搜索内容发送给 shell 之前，删除 `;`、`&&` 和 `|`。诊断控制台仍会运行 `grep $title images/*.txt` 或 Windows 上对应的 `findstr` 命令，因此你需要找到能够绕过过滤的语法。

课程启动时会在 `command-injection/task4/<username>/api-key.txt` 中为你存放一个 API 密钥。绕过过滤器，读取该文件，然后在下方输入密钥以完成任务。

在 Unix 上，可以尝试命令替换，例如 `$(...)`，或注入换行符。在 Windows 上，过滤器会移除 `&&`，却漏掉单独的 `&`；此外，`type` 命令可以读取密钥文件。
