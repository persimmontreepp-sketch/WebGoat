=== 总结：强化命令执行

cat 图库演示表明，一个辅助脚本很快就可能变成远程代码执行（RCE）的工具。
在生产环境中应遵循以下原则：

- 需要执行命令时，尽量避免使用 shell。
使用 `ProcessBuilder` 或同类 API，指定固定的可执行文件，并将参数分别传入。
- 对诊断命令实施严格的允许列表。
经过加固的代码应拒绝所有不在批准集合中的内容。
- 即使采用允许列表，也要验证用户输入。将清理输入视为额外控制措施，而非主要防御手段。
- 使用遵循最小权限原则的账户执行命令，并按用户/会话隔离临时工作目录。
- 记录命令调用和失败，以便检测和响应，但不要泄露机密。

结合应用层监控实施这些控制，让运维人员能够审计诊断控制台，同时避免记录机密。
