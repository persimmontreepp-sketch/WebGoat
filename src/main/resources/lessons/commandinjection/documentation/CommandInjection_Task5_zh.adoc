=== 隔离诊断功能

现在由你控制诊断控制台。团队提出了三个开关：

*执行模式*

- Shell：使用 `/bin/sh -c` 或 `cmd.exe /c` 启动 shell 的旧行为
- 直接进程：不使用 shell，通过 `ProcessBuilder` 执行
- 固定允许列表运行器：只直接运行固定列表中的命令

*命令允许列表*：启用预先定义的安全命令（`hostname`、`uptime`）。

*输入清理器*：删除明显的命令分隔符。

提交一份配置。服务器会运行合法的 `hostname` 检查、一条链接命令注入探测，以及未获批准的 `whoami` 命令。安全配置必须允许状态检查、阻止两种攻击，并避免使用 shell。

安全修复应移除 shell 并实施严格的允许列表。仅使用拒绝列表或输入清理器并不足够。固定允许列表运行器自带允许列表，因此无需启用单独的允许列表开关。
