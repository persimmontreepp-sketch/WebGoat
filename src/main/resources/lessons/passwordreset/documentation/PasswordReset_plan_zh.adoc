= 密码重置

== 概念

本课程介绍密码重置功能。它往往是应用中容易被忽略的部分，可能导致各种有趣的逻辑漏洞。

== 目标

学习如何在应用中安全地实现密码重置功能。

== 简介

我们每个人都曾使用过网站的密码重置功能。不同网站的实现方式各不相同。有些网站要求你回答安全问题，另一些则会向你发送包含激活链接的电子邮件。本课程将介绍一些最常见的密码重置功能，并展示它们可能出错的地方。

仍有一些公司会通过电子邮件以明文形式向用户发送密码。示例请参阅 http://plaintextoffenders.com/。你可以在此找到仍通过电子邮件发送明文密码的网站。这不仅会让你质疑网站的安全性，也意味着它们以明文形式存储密码！
