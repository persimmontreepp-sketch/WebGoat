== 安全问题

很多网站一直存在这样的问题：用户忘记密码后，网站会询问注册时填写的安全问题。通常问题列表是固定的，且有时答案选项也有限。为了使用此功能，用户应能够自行选择问题并输入答案。这样用户就不会都使用相同的问题，攻击者也就更难猜中。

需要牢记，安全问题的答案应受到与数据库中存储的密码相同级别的保护。如果数据库泄露，攻击者不应能够根据安全问题答案重置密码。

如今用户在社交媒体上分享了大量信息，因此很难使用安全问题重置密码。关于安全问题的一个不错资源是：http://goodsecurityquestions.com/

== 练习

只要正确回答秘密问题，用户就能找回密码。“忘记密码”页面没有锁定机制。你的用户名是 `webgoat`，最喜欢的颜色是 `red`。目标是找回另一位用户的密码。可以尝试的用户名包括：`tom`、`admin` 和 `larry`。
