== 创建密码重置链接

创建密码重置链接时，需要确保：

- 链接唯一并包含随机令牌
- 链接只能使用一次
- 链接仅在有限时间内有效

使用随机令牌意味着攻击者无法通过不断阻止用户来轻易对网站发动 DOS 攻击。链接只能使用一次，可防止用户再次更改密码。设置超时时间是限制攻击窗口所必需的。链接一旦泄露，攻击者就会获得很多可乘之机。

== 练习

试着将 Tom（tom@webgoat-cloud.org）的密码重置为你自己选择的密码，然后使用该密码以 Tom 的身份登录。注意：本课程无法使用 OWASP ZAP。此外，浏览器可能无法完成操作；`curl` 等命令行工具通常更适合此攻击。

Tom 对密码问题反应很快。收到包含重置链接的电子邮件后，他总会立即重置密码。
