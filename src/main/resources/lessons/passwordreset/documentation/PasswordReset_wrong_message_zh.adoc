== 判断账户是否存在

如前所述，在密码重置过程中，网站通常会根据电子邮件地址是否存在而显示不同消息。这看起来或许不是什么大问题，但会给攻击者提供信息，供其用于网络钓鱼。如果攻击者知道你在某网站注册了账户，就可以创建钓鱼邮件并发送给你。由于你在该网站确实有账户，你可能更容易点击邮件。另一方面，这对某些网站来说并不重要，但有些用户确实希望拥有更多隐私。
