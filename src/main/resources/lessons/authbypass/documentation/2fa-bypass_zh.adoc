== 双因素认证绕过：密码重置

一个典型的认证绕过案例来自 2016 年的事件（https://henryhoggard.co.uk/blog/Paypal-2FA-Bypass）。用户无法接收短信验证码，于是选择了通过安全问题验证的替代方式。使用代理工具后，他完全移除了请求参数，最终绕过了验证。

image::images/paypal-2fa-bypass.png[Paypal 双因素认证绕过,1397,645,style="lesson-image"]

=== 场景

你正在重置密码，但使用的地点或设备不受服务提供商信任，因此需要回答预先设置的安全问题。问题在于，安全问题的答案保存在另一台设备上（而你没有带在身边），你也不记得答案。

你已经输入用户名或电子邮件地址，并选择了替代验证方式。
